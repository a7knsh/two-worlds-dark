# Ashen Vigil (working title) - Stage 1

Open this folder in Godot 4.3+ (godotengine.org, free) and press F5.

Controls: WASD move | Space roll | J or LMB light attack | K or RMB heavy | Q lock-on
Gamepad: left stick, X light, Y heavy, B roll, R3 lock-on

Run tests: godot --headless --path . --script res://tests/test_stage1.gd
Export: Project > Export > add Linux and Windows presets.
